# Personal Portfolio Website — Faika Khan

A modern, responsive personal portfolio website built to showcase my projects, skills, and experience as a Full Stack Developer.

## Live Preview
https://github.com/workonprofession06-prog/web-portfolio.git

## About the Project

This portfolio highlights my work, technical skills, and problem-solving approach through real-world projects.

It includes:
- Featured projects with descriptions
- Case study section (Problem → Solution → Result)
- Skills & tech stack visualization
- Certifications and learning progress
- Interactive FAQ section
- Contact section for opportunities

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend Concepts:** Django (for showcased projects)
- **Styling:** Custom CSS, Bootstrap, Tailwind (concepts)
- **Icons:** Devicon
- **Other:** Intersection Observer API, LocalStorage


##  Features

-  Light/Dark Mode Toggle
-  Fully Responsive Design
-  Animated Skill Bars & Counters
-  Smooth Scroll & Reveal Animations
-  Dynamic Data Rendering using JavaScript
-  Interactive FAQ Section
-  Scroll-to-top button

## Case Study Highlight

### Student Management System

**Problem:**  
Manual record handling caused inefficiency and errors.

**Solution:**  
Developed a Django-based web system to manage:
- Student records
- Attendance
- Fees
- Reports

**Result:**  
-  70% reduction in admin time  
-  Eliminated manual errors  
-  Real-time data access
